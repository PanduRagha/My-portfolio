## 📖 Description
This project is developed as part of **Task 1 of the CODTECH Internship**.  
The objective of this project is to create a visually appealing personal portfolio website using modern CSS animations and animation libraries such as **GSAP** to provide smooth transitions and interactive effects.

## 🎯 Objective
- To design a professional personal portfolio website
- To use modern CSS animations and smooth transitions
- To enhance user experience using animation libraries like GSAP
- To showcase personal skills, projects, and contact details

## 🛠️ Technologies Used
- HTML5
- CSS3 (Modern Animations & Transitions)
- JavaScript
- GSAP Animation Library

## ⚙️ Features
- Responsive personal portfolio layout
- Smooth scrolling and animated transitions
- Animated sections using GSAP
- Clean and modern user interface
- Sections for About, Skills, Projects, and Contact

## 🚀 How to Run the Project
1. Download or clone the repository
2. Open the `index.html` file in any modern web browser
3. Explore the animated portfolio website
